# Suraksha – Women Safety Application 🚨

## 📖 Overview

Suraksha is an Android-based women safety application designed to provide immediate assistance during emergency situations. The app focuses on enabling quick alerts, real-time tracking, and smart emergency triggers to enhance personal safety.

---

## ✨ Key Features

### 🚨 Emergency & Alert System

* **SOS Emergency Alert**
  Instantly notifies pre-selected contacts during emergencies.

* **Live Location Sharing**
  Sends real-time location to trusted contacts for quick response.

---

### ⏱️ Smart Safety Features

* **Safety Check-in Timer**
  Allows users to set a timer while traveling or in uncertain situations.
  If the user does not check in before the timer expires, an automatic alert is triggered.

* **Volume Button Trigger**
  Enables discreet emergency activation by pressing the device’s volume button multiple times.
  Useful in situations where accessing the app is not possible.

---

### 📞 User Convenience

* **Emergency Contact Management**
  Add, edit, and manage trusted contacts.

* **Quick Emergency Call**
  One-tap calling feature for immediate help.
