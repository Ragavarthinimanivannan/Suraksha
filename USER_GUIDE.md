# User Guide – Suraksha App

## 📌 Introduction
Suraksha is a women safety application designed to provide quick assistance during emergencies.

## 🚀 How to Use

### 1. Add Emergency Contacts
- Open the app
- Navigate to contacts section
- Add trusted contacts

### 2. Trigger SOS Alert
- Press the SOS button
- Emergency message with location will be sent

### 3. Use Safety Timer
- Set a timer while traveling
- If not stopped, alert will be triggered automatically

### 4. Volume Button Trigger
- Press volume button multiple times
- Emergency alert will activate silently

## ⚠️ Note
Ensure location services are enabled for accurate tracking.
